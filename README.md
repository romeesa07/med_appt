# Medical Appointment Booking

## Project Overview

Medical Appointment Booking is a web application developed for StayHealthy Inc. to help patients connect with doctors and specialists for online consultations and medical appointments.

## Features

- Search for doctors
- View doctor information and ratings
- Book medical appointments
- Manage appointments
- Provide consultation feedback
- Manage user profiles
- Responsive and user-friendly interface

## Technologies

- HTML
- CSS
- React.js
- JavaScript
